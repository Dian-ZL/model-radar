# 模型技术跟踪

打开 `index.html` 即可离线查看站点。原始资料链接需要联网。第一阶段跟踪 LLM，当前以 14 家厂商的有代表性版本为起点。

## 内容维护

- 早期版本和算法标签关系见 `app.js`。后续版本可在 `releases.js` 中增补，记录版本日期、来源、模型参数、访问方式、算法和已验证的部署信息。
- 通用算法解读和示意见 `technique-guides.js`。C4A 的解读位于 `app.js`。
- 保留事实对应的一手来源。允许缺失字段，页面会显示待核验。训练与推理格式要注明适用对象。性能必须保留硬件、框架、精度、并行、长度、批量和基线等已知条件。
- 定期核对官方发布和模型卡。发布事件、API 更新与权重发布时间分别核验。维护已有版本记录，以便比较历史变化。

## 发布到 GitHub Pages

目标仓库为 `Dian-ZL/model-radar`。创建仓库并提交本项目至 `main`，在 **Settings → Pages → Source** 选择 **GitHub Actions**，随后手动运行 **Publish model radar**。后续推送到 `main` 时工作流会更新站点。

查看 Actions 的部署结果，以工作流给出的站点 URL 为准。工作流只打包静态网页文件。
